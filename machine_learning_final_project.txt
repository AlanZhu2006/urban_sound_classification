Abstract 
Abstract: This report presents a multi-Resolution Ensemble Framework with pseudo-labeling based on CRNN. Addressing the issues of limited labeled data and high inter-class similarity, we developed a three-stage pipeline: (1) High-efficiency parallel preprocessing, (2) Heterogeneous teacher training with pseudo-labeling (3) Dense multi-resolution ensemble inference. 
1 Introduction 
Audio classification involves categorizing audio recordings into different classes. The primary chal-lenges include variable audio lengths, background noise, and acoustic similarity between classes. This project implements an end-to-end pipeline that transforms raw waveforms into Log-Mel Spectrograms and utilizes a heterogeneous ensemble strategy to capture both temporal dynamics and spectral textures. 

2 Data Preprocessing 
To address the I/O bottleneck and standardize inputs, we implemented an offline feature extrac-tion pipeline (preprecess.py). Important: All the script I submitted has to be run in a Kaggle Notebook environment where the dataset is mounted. 
2.1 Audio Standardization 
All raw audio files were resampled to a uniform sampling rate of 22, 050 Hz. This value was chosen to preserve frequencies up to ¡Ö 11 kHz (Nyquist limit), covering the dominant frequency bands of urban sounds while minimizing computational overhead. We set the maximum frequency (fmax) to 8 kHz to focus on perceptually relevant frequency bands and reduce high-frequency noise. 
. Duration Normalization: To ensure a fixed tensor shape for the neural network, we standardized audio duration to 4.0 seconds. Clips shorter than 4s were padded with silence, while longer clips were truncated. 

2.2 Feature Extraction: Log-Mel Spectrograms 
Instead of raw waveforms, we utilized Log-Mel Spectrograms to mimic human auditory perception. The extraction parameters were tuned as follows: 
. 
FFT Window (n_fft): 2048.(default value in librosa) This large window provides high frequency resolution, critical for distinguishing harmonic structures. 

. 
Hop Length: 512. This determines the temporal resolution. 

. 
Mel Bands (n_mels): 128. 

. 
Logarithmic Scaling: A power_to_db conversion was applied to compress the dynamic range, making the features robust to volume variations. 


The final output is a tensor of shape (128, 173). To accelerate training, these features were serialized as .npy (float32) files using parallel processing (joblib, n_jobs = .1). 


3 Methodology(train.py) 
Our proposed solution utilizes a "Teacher-Student" framework designed to overcome data scarcity. The workflow consists of a "Teacher" phase (implemented in train.py) responsible for feature learning and pseudo-label generation, and a "Student" phase (implemented in main.py) focused on dense inference and error correction.

3.2 Semi-Supervised Self-Training (Pseudo-Labeling)

.

To optimize the ensemble weights, we employ a Hill Climbing heuristic algorithm on the Out-Of-Fold (OOF) predictions, enabling us to mathematically derive the optimal contribution of each model. 

. 
Step 2: High-Confidence Pseudo-Labeling: The optimized teacher ensemble predicts labels for the unlabeled test set. We apply a strict confidence threshold to filter these predictions:

5 Post-Processing: Dynamic Conflict Resolution(main.py) 
Raw softmax probabilities are often biased due to class imbalance and acoustic similarities. We implemented a three-stage post-processing pipeline to refine predictions based on expert rules derived from Confusion Matrix analysis.

5.2 Confusion Matrix Analysis & Decision Boundary Calibration 
By analyzing the off-diagonal errors in the Confusion Matrix, we identified systematic biases where the model favored dominant acoustic textures over subtle ones. To address this, we implemented a two-stage calibration strategy. 
5.2.1 Static Class Weighting 
To counter the imbalance between Precision and Recall, we applied a static correction vector Wclass to the final probabilities. 
Wclass = [1.85, 1.00, 0.85, 0.95, 1.25, 1.10, 1.00, 0.65, 1.35, 0.55] (7) 
The logic is two-fold: 
1. 
Boosting Low Recall: We assigned high weights (e.g., w0 =1.85) to classes like Air Conditioner, which suffer from high False Negative rates, effectively penalizing the model for missing these samples. 

2. 
Suppressing Low Precision: Conversely, we assigned lower weights (e.g., w9 =0.55) to classes like Street Music that act as "broad attractors," thereby suppressing False Positives and forcing the model to be more conservative. 



5.2.2 Dynamic Conflict Resolution 
We calibrated the decision boundary to correct the model¡¯s systematic bias towards the dominant class, maximizing the F1-score on the validation set.
